# 民生通報決策分析 v1.0

## 1. 政策問題與適用範圍

本獨立 POC 支援 Observe → Compare → Prioritize → Simulate → Review → Export：在明確資料期間及可調假設下，選出有限數量的「行政區 × 服務主題」供政策分析者進一步調查。不是政府實際派案、緊急應變或公共衛生風險評分。

## 2. 派工資料與一般陳情的差異

來源是[臺北市政府 1999 派工資料](https://data.taipei/dataset/detail?id=b796f87a-0ed8-4e57-89f6-225a4941b1ed)，不是所有市民陳情。核心欄位是案件編號、派工項目、案件地址、立案日期及時間。通報頻率不等於實際問題發生率；無法推論嚴重度、影響人口、處理完成時間、滿意度或目前案件狀態。

## 3. 現有架構與新模組

保留 Vite / React / TypeScript、靜態 GitHub Pages、既有四個模組、紀錄預覽、年度分檔及共用請求快取。新增導覽按鈕採 lazy import，開啟時只取 `data/civic-decision/snapshot.json`，不下載 150,000 筆案件。情境由純 TypeScript 函式在瀏覽器執行。巢狀決策資料納入部署快取指紋。

## 4. 資料來源與來源期間

以官方目錄列出的月檔與本地歷史留存為來源。2026-10-16 稽核確認目錄最新列出 2026 年 9 月資料，資源更新日為 2026-10-05；實際可評分月份以 snapshot 的 `complete` 狀態為準，不能用任務日期猜測最新月份。公開來源稽核保留每檔資源 ID、URL、期間、更新日、取得日、轉換日、位元組雜湊、編碼、schema 及列數。舊 API 重組 CSV 的雜湊不冒充原始下載雜湊。

## 5. 資料品質及月份完整性

`complete` 須有官方月資源契約與完整下載/位元組及欄位驗證；有紀錄不代表完整。`partial`、`missing`、`schema-inconsistent`、`unknown` 都不能評分。月格於瀏覽器紀錄上限套用前建立。缺月份不補零；只有完整來源範圍內明確建立的零格可視為零。

重複案件於離線程序去重，無效日期不進入彙整；無法辨識的行政區與未核定項目單獨記錄排除。來源修訂使用不可變的 staging 檔，不覆寫既有來源。失敗時不發布新 snapshot，保留已知良好輸出。

## 6. 服務類別定義

版本化 mapping 採官方派工項目的精確名稱，保留原標籤。五類為垃圾清運服務、污染舉發、噪音舉發、道路與公共空間維護、排水環境維護。詳見 `src/lib/civicCategoryMapping.ts` 與公開 category mapping。未知及有編碼疑義的項目不透過關鍵字猜測。

大型廢棄物清運聯繫代表清運服務需求，不代表非法棄置；鄰里無主垃圾清運代表清潔派工；污染舉發為廣泛分類，不代表已確認污染或鼠患。動物救援不納入鼠患統計。

## 7. 調查優先順序方法

`civic-investigation-priority-v1` 的預設為最近三個完整月份，對前面緊接的三個完整月份。兩期間相鄰、連續、等長、不重疊；不能跳過缺月。資料不足時只提供描述或證據不足。

A 優先調查：近期至少 10 筆、至少 2 個月有紀錄、基期至少 5 筆、增加至少 25%，且全部資料與分類驗證通過。

B 例行調查：近期量與持續性達標，或具至少 5 筆基期的 25% 成長，但未滿足 A 全部條件。

C 持續觀察：資料可比但未達 A/B。無資料、抑制格、缺月或不完整來源為證據不足，排除名單。零基期不顯示百分比成長。

同層級依絕對增加、近期月均量、活動月份數、穩定行政區識別及主題識別排序。延長或縮短期間，筆數門檻依月數/3 等比例調整；活動月門檻同倍率後向上取整。畫面揭露這項分析假設。

## 8. 情境與敏感度

容量可選無限制、5、10 或自訂；代表檢視組合數，不代表公務機關派案。比較預設、較寬鬆、較嚴格假設及不同容量，保持來源版本、mapping、篩選與月份不變；列出納入、排除、層級/排序變更及不變者。名單涵蓋量只加總互斥區域/項目群，不估計改善成效、成本節省或鼠患減少。

## 9. 個資與空間保護

新公開資產只含固定月 × 行政區 × 核定項目的彙整，不含原始地址、門牌、樓層、聯絡人、案件識別碼或精確座標。1–4 筆格設為 null；包含抑制格的衍生合計及候選者一併隱藏，不將 null 當零。CSV 防止公式注入，JSON 匯出由明確欄位建立並重算情境。

此門檻是保守分析預設，並非法律安全港。固定分組及不發布可還原的重疊總計減少差分洩漏；既有公開來源或跨版本對照仍可能帶來連結風險，不能承諾絕對匿名。

## 10. 環境治理及鼠患限制

[市府 2026-02-06 跨局處防鼠政策](https://www.gov.taipei/News_Content.aspx?n=F0DDAF49B89E9413&s=110037E83F097031)僅作政策脈絡，不是案件資料。本次未驗證可合法用於此模組的鼠患專屬逐月行政區資料，因此鼠患分類、熱點及商家排名不提供；不將廣泛環境服務當鼠患代理變數。

## 11. 決策摘要與驗收

摘要說明問題、來源與期間、涵蓋範圍、前後觀察、名單、規則與選取理由、完整性、隱私、限制及待機關/現場確認問題。下載 JSON 與 CSV 不含個案。驗收執行 `./init.ps1`、Pages 建置、ETL/決策/隱私回歸及桌面/手機檢查；詳細證據見 progress.md。

## 12. 下一階段

取得來源端完整性及分類沿革的正式契約，補齊歷史月下載證明、加入同季對照及人口分母的適用性審查。未來市場、清潔、病媒防治或環境稽查資料只能以經驗證的行政區/期間彙整整合，保留來源語意與版本；沒有合法識別與授權不做個案連結。不呼叫其他作品網站的瀏覽器 API，不把商家名稱與派工連結推論責任。
